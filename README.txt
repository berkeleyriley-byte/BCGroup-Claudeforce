HOW TO UPDATE
  1. Back up your current index.html and images folder.
  2. Upload index.html to the web root, replacing the old one.
  3. Upload the four files above into the existing /images/ folder
     (the old images there can stay; the new page does not use them).
  4. Hard-refresh the site (Ctrl/Cmd + Shift + R).
